# Kaggle Titanic Survival Prediction 🚢

欢迎来到我的数据科学起航之旅！这是我完成的第一个机器学习模型。

## 🌟 项目简介
本项目是 Kaggle 经典竞赛 [Titanic - Machine Learning from Disaster](https://www.kaggle.com/c/titanic) 的解决方案。我通过这个项目初步掌握了数据清洗、特征工程以及分类模型的全流程。

## 📊 模型表现
* **当前算法**: 逻辑回归 (Logistic Regression)
* **Kaggle 公测分数**: 0.76315
* **核心逻辑**: 通过对性别、舱位等级、年龄（条件中位数填充）等特征的分析，预测乘客在灾难中的生还概率。

## 📂 目录结构说明
* **`/Data`**: 包含竞赛提供的源数据（`train.csv`, `test.csv`）。
* **`/Codes_and_results`**: 核心代码与产出文件夹。
    * `Analysis.ipynb`: 详细的实验笔记，记录了数据探索、可视化和踩坑经历。
    * `Logistic.py`: 整理后的纯 Python 执行脚本，适合直接部署运行。
    * `submission_final_logistic.csv`: 模型生成的最终预测结果文件。

## 📈 进化之路
这个项目仅仅是一个开始。
1.  **从零到一**: 我从最基础的 `ValueError` 报错处理开始，一步步理解了数据对齐和 Git 版本管理。

3.  **保持开源**: 我会不断更新这个仓库，并将后续所有 Kaggle 竞赛的探索过程和模型全部开源到 GitHub。

* **Kaggle Public Score**: 0.76315

## 📂 Directory Structure
* **`/Data`**: Contains the raw datasets provided by the competition (`train.csv`, `test.csv`).
